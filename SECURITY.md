# Security policy

voidfs stores other people's data and holds credentials for their buckets, so security reports
are taken seriously.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability reporting: the
**Security** tab of the repository, then **Report a vulnerability**.

Include what you found, how to reproduce it, and the impact you believe it has. You will get an
acknowledgement within 3 working days. Fixes are released before details are published, and
reporters are credited unless they ask not to be.

## Supported versions

voidfs is pre-release. Until 1.0, only the latest commit on `main` receives security fixes.
